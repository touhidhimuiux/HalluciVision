## Overview

**HalluciVision** investigates object hallucination in Large Vision-Language Models (LVLMs)—a reliability problem in which models describe objects or visual details that are not supported by the input image.

We explore two complementary approaches:

- **Attention-based intervention:** Investigating visual-token attention and adapting the training-free EAZY approach to analyze and intervene in model representations.
- **Visual occlusion analysis:** Examining how removing image regions using FastSAM affects model-generated captions and their similarity to human references.

The study evaluates three quantized vision-language models using MS COCO 2014 validation images.

## Research Objectives

1. Investigate object hallucination in vision-language models.
2. Analyze attention patterns between generated text tokens and visual tokens.
3. Explore EAZY-based training-free hallucination detection and intervention.
4. Compare baseline and visually grounded prompting strategies.
5. Evaluate model responses under progressive visual occlusion.
6. Examine the limitations of reference-based caption evaluation.

## Experimental Framework

| Experiment | Method | Evaluation Scale |
|---|---|---|
| Attention Analysis | EAZY-based token analysis and intervention | 10 images |
| Prompt Evaluation | Baseline vs. grounded prompting | 500 images |
| Occlusion Study | FastSAM visual masking | 500 images, 3 masking levels |
| Caption Evaluation | BLEU-4, ROUGE, BERTScore, CIDEr | 3 models |

### Research Pipeline

MS COCO Images → Vision-Language Models → Caption Generation → Prompt Comparison → FastSAM Occlusion → Caption Evaluation → Comparative Analysis

**Additional investigation:** Visual-token attention analysis → EAZY candidate detection → PyTorch representation intervention.

## Key Experimental Findings

### Prompting strategy affected models differently

The grounded prompt improved all five reported reference-based metrics for LLaVA-1.5-7B, while decreasing them for both Qwen models.

### Visual occlusion revealed model-dependent behavior

FastSAM masking produced different responses across architectures. LLaVA and Qwen2-VL generally showed decreasing BERTScore-F1 as more image content was masked, whereas Qwen2.5-VL-3B showed a different baseline pattern.

###  EAZY intervention showed promising pilot results

In the 10-image LLaVA pilot, the reported image-level candidate rate decreased from 50% under greedy decoding to 10% with EAZY (K=5). These candidate labels were generated by the detection procedure and were not independently verified ground-truth hallucination labels.

## Limitations

- The study focuses on MS COCO image captioning.
- EAZY evaluation is a limited 10-image pilot.
- Reference-based caption metrics do not directly measure object hallucination.
- No statistical significance testing was reported.
- Quantization and generation-length constraints may affect model behavior.

## Future Research

- Extend hallucination evaluation using CHAIR and POPE.
- Introduce independent visual-grounding annotations.
- Investigate attention-based hallucination detection.
- Evaluate robustness under additional visual perturbations.
- Explore more reliable evidence-grounded VLM evaluation.
